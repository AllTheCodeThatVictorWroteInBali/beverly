# Beverly

<img src="assets/beverly_logo_final.png" alt="Beverly brand mark" width="280" />

Beverly is a Rust-native UI system for Bevy that helps teams build high-performance, accessible interfaces for data-heavy and AI-driven applications.

It is designed for applications that need a native ECS-first foundation, reusable UI composition, and polished visual treatment without sacrificing performance or clarity.

## Why Beverly?

Beverly brings together the pieces that modern native software needs:

- a structured component library grounded in Bevy
- reusable layout primitives for dashboards and workspaces
- semantic and accessible interaction defaults
- material-driven rendering for polished surfaces and effects
- a design system that supports both dense data UIs and AI-oriented workflows

## Design principles

- Performance first
- Accessibility by default
- AI interaction that remains transparent and user-controlled
- Data sovereignty and local-first thinking
- Clear visual hierarchy over decorative complexity

## What this documentation covers

This book is organized around the real system layers that a Beverly app depends on:

- foundations and design tokens
- reusable components and layout patterns
- rendering, materials, and shader-backed effects
- interaction, motion, and accessibility guidance
- data-heavy, media, and AI-oriented examples

For a high-level view of the system architecture, see [Architecture](./architecture.md). For a working starting point, see [Getting Started](./getting-started.md).
