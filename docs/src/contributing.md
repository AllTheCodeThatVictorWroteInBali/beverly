# Contributing

<img src="assets/beverly_logo_final.png" alt="Beverly brand mark" width="280" />

Contributions to Beverly should focus on clear API design, performance, and accessibility.

## Principles
- Prefer reusable primitives over app-specific widgets
- Keep interactions accessible by default
- Benchmark changes that affect rendering or layout

## Workflow
1. Start with a focused issue or proposal
2. Add tests for behavior changes
3. Update docs when API changes
4. Run cargo fmt and cargo test
